# Extended VFS in Linux

This repository is a development fork of a collaborative codebase [https://github.com/dchen22/evfs-docs/](https://github.com/dchen22/evfs-docs/) built for an academic research project focused on linux VFS development. Its purpose is to reduce the effort in the development of file system management software.

For more information see our wiki here: [https://github.com/pexwl/linux-evfs/wiki](https://github.com/pexwl/linux-evfs/wiki)
